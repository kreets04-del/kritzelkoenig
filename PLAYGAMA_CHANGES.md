# Kritzelkönig — what changed after the AI rejection

This document lists the concrete design and code decisions taken in response to
Playgama's feedback that the game read as unedited generative output.

The core mechanic was deliberately **not** changed. Kritzelkönig already works and
its existing players enjoy it. The rejection was about the surface, not the game,
so the surface is what was reworked — by removing generated art and replacing it
with things that were drawn, decided and tuned by hand.

**Package size: 7.83 MB → 0.96 MB.** The shipped build now makes **zero image
requests**. Every graphic in the game is drawn by the document itself.

---

## 1. Human-curated visual design

The game already had the right idea — a chalk-doodle look — but it was carried by
generated raster art in a completely different style: glossy, beveled, evenly lit
3D-ish vector icons sitting on top of a chalk background. Two visual languages in
one screen. That mismatch is exactly what "different graphic styles" means in the
review notes.

Everything visible was redrawn in **one** language: monoline strokes, round caps,
slightly irregular geometry — the look of something drawn with a pen, which is
what a drawing game should look like.

| Element | Before | Now |
|---|---|---|
| Title wordmark | 1376×768 PNG, glossy 3D lettering | Hand-lettered SVG, one stroke path per letter |
| Background | 768×1376 PNG, chalk doodles + two generated light blooms | Doodle field generated at runtime from 12 hand-drawn motifs |
| Tool icons (4) | 1024×1024 PNGs shown at 24 px | Inline SVG symbols |
| Winner graphic | 1024×1024 PNG | Hand-drawn SVG crown |

### The wordmark

"KRITZELKÖNIG" is set in a stroke alphabet written for this game — ten letterforms,
two to four strokes each. Each letter is offset and rotated by a small fixed
amount, so the word sits unevenly the way handwriting does, and the crown over the
second K is drawn as a doodle rather than a symbol. The offsets are **constants,
not random**: the title must look identical on every visit, otherwise it is noise
rather than a design.

### The background

The old background was a single portrait-format image stretched to `cover`. On a
landscape monitor it was cropped; on a phone in landscape it was cropped harder.
It also carried two soft coloured glows that matched nothing else in the game.

It is now generated by `kritzelgrundZeichnen()`: twelve doodles (cat, star, heart,
house, balloon, sun, crown, tree, fish, ice cream, flower, cloud), each hand-drawn
as stroke paths, scattered on a heavily jittered grid sized to the actual viewport.
A seeded generator (`mulberry32`, fixed seed) means the layout is stable across
reloads. Opacity runs 5.5–13 %, deliberately low: **the player's drawing is the
picture that matters, not the wallpaper.**

## 3. Custom UI

Components designed specifically for this game:

- **Icon set** — pencil, eraser, undo, clear, crown, word-choice, speech bubble.
  Drawn on a 24-unit grid at 1.7–1.9 stroke width so they sit together as a family.
  They use `currentColor`, so the active tool button tints its icon dark on the
  yellow highlight without a second asset.
- **The "clear" icon is a sheet being wiped, not a waste bin.** You are clearing a
  drawing, not deleting a file.
- **The "choose" icon is three word cards with the middle one lifted** — literally
  what the artist sees at the start of a round.
- **Start screen** — the title, one line saying what the game is, and the loop in
  four steps: Choose → Draw → Guess → Next artist.
- **Round-end panel** — rebuilt from an icon-and-number string into named lines
  (see §5).
- **Match Gallery** — see §6.
- **Lobby note** — states plainly that the game is played with real people and that
  sharing the link is the next step.

Consistency rules applied throughout: one accent colour (`--accent`) for anything
the player should look at, one secondary (`--accent2`) for scores, `--muted` for
labels, the same corner radii, and the same `@media (max-height: …)` breakpoints
used everywhere rather than per-component guesses.

## 4. Hand-tuned gameplay

Values were reviewed one by one. Most were already deliberate and were kept —
listed here with the reasoning rather than changed for the sake of changing.

| Value | Setting | Why |
|---|---|---|
| `ROUND_SECONDS` | 90 s | Long enough to draw something recognisable without rushing, short enough that a 10-round match stays under 20 minutes. |
| Word options | 3 | Enough choice to avoid a dead round, few enough to decide in seconds. More options means more stalling. |
| Hint reveals | 60 / 40 / 20 / 10 s | Front-loads the challenge. Nothing is given away in the first third; help arrives once guessing has genuinely stalled. |
| Speed bonus | ×2 under 15 s, ×1.5 under 30 s | Rewards reading a drawing fast, which is the actual skill. |
| Difficulty bonus | ×1 / ×1.25 / ×1.5 | Picking the hard word is a risk; it should pay. |
| Artist share | half the guesser's points | Makes drawing well worth it. Deliberately sabotaging a drawing earns nothing. |
| Round advance | manual "Continue" | The drawing stays on screen after the reveal so people can react to it. That pause is where a party game actually happens. |
| Lightning badge | ≤ 10 s | Rare enough to stay meaningful. |
| Last-second badge | ≤ 5 s remaining | Same reasoning from the other end. |
| Interstitial timing | once at half-time, from 20 rounds up | Short matches are never interrupted. Long ones get exactly one break, at a natural seam. |
| Banners | menu and lobby only | Never during a round. |

## 5. Social mechanics

The point of the game is that other people are on the other side. That was
previously almost invisible in the UI.

**Round end — before:** `✅ Tom +42 · ✏ Anna +21` plus the word.
**Round end — now:**

```
THE WORD WAS   ALPAKA
ARTIST Anna +99   FIRST CORRECT GUESS Tom +198   GUESSED IN 11.1 s
                          Tom is the next artist!
```

The solve time is measured on the server from the actual round start, not derived
from the whole-second countdown, so it reads 11.1 s rather than 11 s.

**Event messages added:**

| When | Message |
|---|---|
| You become the artist | Your turn to draw! |
| Round starts, 3+ players | *n* players are guessing |
| 10 seconds left | Only 10 seconds left! |
| Solved in under 10 s | ⚡ Lightning guess! |
| Solved with under 5 s left | ⏱ Last second guess! |
| Nobody solved it | That one was tricky! |

The badges are deliberately **not** shown every round. Something that appears every
time stops being an event and becomes decoration.

**The solo-vs-computer mode is hidden in portal builds.** It remains on our own
site, where it is useful when nobody else is online. But a player — or a
reviewer — opening Kritzelkönig on a portal should not find that the first thing
on offer is a match against a bot. This game is people drawing for people, and
that has to be the first impression.

## 6. Player-generated content

**The drawings shown during gameplay are created live by the players themselves.**

Nothing in a match is authored ahead of time. One player picks a word and draws it
with the mouse or a finger; every stroke is transmitted to the others as it
happens; they type guesses; the first correct guess takes over the pen. The
drawings, the wrong guesses, the laughter and the competition are all produced by
the people in the room.

To make that visible rather than merely true, the game now ends with a
**Match Gallery**: thumbnails of the drawings that were actually made during that
match, each labelled with the word and the player who drew it.

Implementation is deliberately light. Every client already holds the strokes of
every round, because it drew them. At the end of each round the client snapshots
its own canvas into a 190×190 WebP thumbnail (~2 KB) and keeps it in memory. There
is **no server involvement, no storage, and no upload** — the gallery lives until
the match ends and then it is gone. Capped at 16 entries.

## 7. Sound direction

Every effect previously played at the same volume, 0.55. That meant the tick that
fires five times in a row during the final seconds was as loud as the victory
sound that plays once per match.

Levels are now staged by role:

| Sound | Level | Reasoning |
|---|---|---|
| `correct` | 0.60 | The moment of the round. Should cut through. |
| `win` | 0.65 | Once per match. Slightly louder or the ending falls flat. |
| `round_start` | 0.42 | Transition to the next artist. Noticeable, not startling. |
| `tick` | 0.30 | It repeats. Quiet. |
| `click` | 0.22 | Barely there. |

**Timer warning:** one clear cue at exactly 10 seconds (a toast plus a single
tick), then ticks only in the last five seconds. Previously nothing happened until
five seconds, and there was no warning at all.

**Button sounds:** `sounds/click.mp3` shipped in the package but was never played.
It is now wired to the buttons that actually advance the game — start, continue,
send guess, choose word. Tools, colour swatches and settings stay silent. Not every
click needs a sound.

**Music** stops when a round is running. Drawing under time pressure does not need
a soundtrack competing for attention.

## 8. Mobile optimization

- The four-step strip on the start screen shrinks below 640 px of height and is
  dropped entirely below 470 px, so the **start button is always reachable without
  scrolling** on a phone held sideways.
- Gallery thumbnails drop from 104 px to 74 px on short screens; the strip scrolls
  sideways rather than growing the dialog.
- Verified at 1280×720, 1280×600, 900×560, 740×360 and 375×812: no vertical
  overflow, start button visible in every case.
- The background regenerates only when the viewport changes by more than ~40 px,
  so the mobile address bar sliding in and out does not reshuffle it.
- Removing the raster assets cut the download from 7.83 MB to 0.96 MB, which
  matters most on a phone connection.

---

## What was deliberately not done

Playgama's note is about too much generated content. **Generating more content
would have been the wrong answer.** No new AI images were produced for this
revision. Everything added is stroke paths, CSS, and code.

The mechanic is untouched: three words, pick one, draw it, first correct guess
takes the pen. No progression system, no collectibles, no achievements. Party
games work because you understand them immediately.
